# programada/deploy-labels Specification

## Purpose

Defines the ProgramADA project deploy button labels: "Jogar" for general playtest and "Jogar MiniGame" for the café mini-game.

## Requirements

### Requirement: Deploy button labeled "Jogar" for playtest

The system SHALL display the button text "Jogar" for the general playtest deploy link in the ProgramADA project.

#### Scenario: "Jogar" button displayed for playtest

- **WHEN** the user views the ProgramADA project demo with the general playtest video
- **THEN** the deploy button SHALL display the text "Jogar" instead of "Deploy"

### Requirement: Deploy button labeled "Jogar MiniGame" for café mini-game

The system SHALL display the button text "Jogar MiniGame" for the MiniGame Café deploy link in the ProgramADA project.

#### Scenario: "Jogar MiniGame" button displayed for café mini-game

- **WHEN** the user views the ProgramADA project demo with the MiniGame Café video
- **THEN** the deploy button SHALL display the text "Jogar MiniGame" instead of "Deploy"
