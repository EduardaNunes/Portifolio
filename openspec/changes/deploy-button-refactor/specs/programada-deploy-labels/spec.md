# Spec Delta

## MODIFIED Requirements

### Requirement: Deploy hover text "Jogar" for playtest
The system SHALL display the hover text "Jogar" for the general playtest deploy link in the ProgramADA project. This text appears in the thumbnail hover overlay per `thumbnail-deploy-hover` capability instead of on a button.

#### Scenario: "Jogar" text displayed in hover overlay for playtest
- **WHEN** the user hovers over the ProgramADA project's general playtest thumbnail
- **THEN** the hover overlay SHALL display the text "Jogar" with deploy icon

### Requirement: Deploy hover text "Jogar MiniGame" for café mini-game
The system SHALL display the hover text "Jogar MiniGame" for the MiniGame Café deploy link in the ProgramADA project. This text appears in the thumbnail hover overlay per `thumbnail-deploy-hover` capability instead of on a button.

#### Scenario: "Jogar MiniGame" text displayed in hover overlay for café mini-game
- **WHEN** the user hovers over the ProgramADA project's MiniGame Café thumbnail
- **THEN** the hover overlay SHALL display the text "Jogar MiniGame" with deploy icon
